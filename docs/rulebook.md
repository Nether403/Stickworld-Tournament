# Stickworld Tournament Player Rulebook — Version 2

The game and platform names in this rulebook are working titles until legal
clearance is complete.

## Ranked play

- Sign in before starting a ranked attempt. Practice runs never become ranked
  scores.
- The server issues the course seed and attempt. Refreshing, leaving, or
  closing the page abandons that attempt.
- Ranked play has no pause. Locking a phone or moving the game to the
  background does not extend the attempt.
- A score counts only after the server replays the recorded inputs and verifies
  the result. A player's highest verified score for each season game is their
  personal best.
- Per-game ties use the game's published tiebreakers, then the earlier time the
  score was achieved. Players still tied share a place.

## Championship

Nine fixed-course games count toward the championship. Pogo Tower is
weekly-only and does not count toward the championship. Each championship game
is worth up to 1,000 points, for a maximum total of 9,000.

Not playing a championship game contributes 0 points. Daily and weekly boards
do not contribute. A championship game remains provisional until at least 50
players have a verified score in it.

Overall ties are resolved in this order:

1. Most championship-game wins.
2. Most top-10 finishes.
3. Highest median across all nine championship-game point values; a missing
   game is 0.
4. Earliest time the championship total was achieved.

Standings show an `as of` time. Closing a season freezes its final snapshot.
