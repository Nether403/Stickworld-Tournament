# Hammer Throw Havoc — inspiration ledger

**Abstract lesson taken**

Building angular velocity and releasing a mass is an unprotectable field event.
Distance plus gates is the score.

**Explicitly excluded from copying**

Olympic venue layouts, branded hammers, mascot throwers, and any third-party
sport-title HUD. No third-party title in code or assets.

**Our independent creative pillars**

- Locked thrower, one hammer body, four vertical gate sensors with a published
  point table.
- Three throws summed in one replay. Tiny input (spin/release edges).

**Asset provenance**

v1: Phaser primitives. Numbers in `docs/games/hammer-throw-havoc.md`.
