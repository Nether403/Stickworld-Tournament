# Hookline Sprint — inspiration ledger

**Abstract lesson taken**

Pendulum traversal is an unprotectable player problem: attach a distance
constraint to a point, swing, release to carry momentum, repeat. Timing a
release is a skill, not an expression.

**Explicitly excluded from copying**

Any third-party course order, hook/anchor placement, trampoline or bumper
shapes, costume sets, HUD arrangement, colour script, sound stings, menu
mascots, or one-tap-only onboarding copy associated with commercial grappling
browser games. No third-party title in code, strings, fixtures, or asset names
(CI grep gate).

**Our independent creative pillars**

- Horizontal **race** with four numbered gates and a time-remaining finish
  bonus, not a themed obstacle-gauntlet campaign.
- Hold-to-attach with keyboard cone-aim and pointer-ray aim; ranked has **no
  pause**.
- Integer combo on perfect releases defined as 92% of that swing's max
  horizontal speed — a published competitive rule, not a hidden juice meter.
- Capsule body, locked rotation, eight authored anchors on a single start ledge
  and void. Visual language is `@stickworld/ui` tokens shared with the rest of
  the platform.
