# Cargo Chaos — inspiration ledger

**Abstract lesson taken**

Hauling an unstable load so that speed trades against condition is an
unprotectable logistics problem.

**Explicitly excluded from copying**

Third-party truck/stacker skins, warehouse campaigns, named cargo companies,
and conveyor-belt set pieces copied from a particular physics toy. No
third-party title in code or assets.

**Our independent creative pillars**

- Integer condition 0–100 with published decay rules.
- Six hitch posts in an original table; two hazard sensors; gapped floors.
- Rope hitch is always on; player hook is for posts, not crate welding.

**Asset provenance**

v1: Phaser primitives. Numbers in `docs/games/cargo-chaos.md`.
