# Ragdoll Archery Rush — inspiration ledger

**Abstract lesson taken**

Ballistic aim plus an unstable body creates suspense. That player problem is
unprotectable. Static scored discs and an integer draw are our expression.

**Explicitly excluded from copying**

Third-party archer silhouettes, bow skins, moving/swinging target choreography
from commercial archery titles, ammo economies, and PvP duel framing. v1
targets are static on purpose. No third-party title in code or assets.

**Our independent creative pillars**

- Frozen ten-body table with a **locked torso plant** (no PD balancer).
- One arrow body from tick 0; no runtime spawn.
- Eight discs with a published point table and streakHundredths(25, 4).
