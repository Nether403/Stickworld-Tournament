# Pickaxe Ascent — inspiration ledger

**Abstract lesson taken**

Climbing with a tool that bites a surface, then using gravity and leverage to
gain height, is an unprotectable physical idea. Precision aiming plus commit/release
is the skill.

**Explicitly excluded from copying**

Third-party cave silhouettes, ice-axe animations, named peaks, upgrade shops,
stamina meters copied from climbing videogames, and any roster or mascot from
stickman compilations. No third-party title in code, strings, fixtures, or
asset names.

**Our independent creative pillars**

- A **vertical shaft** with eight staggered static ledges and checkpoint planes
  every 3 m, scored as altitude + checkpoints + clean-climb streak + finish
  bonus.
- Kinematic pickaxe pose from an integer degree `aim` (deterministic, no motor).
- Same capsule proportions and UI tokens as Hookline, so it reads as the same
  tournament, not a different minigame site.
- v1 has no moving platforms (those wait for Spec 4 Wave B).

**Asset provenance**

v1: Phaser primitives only. Human-authored geometry in
